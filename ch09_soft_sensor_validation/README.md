# 시험 결과를 기다리지 않고 품질을 알 수 있을까?

시멘트도 AI도 처음인 학생을 위한 비전공자판 인터랙티브 해설입니다. 박사 · 조수(하루) · 초파리 연구원 · 주판봇이 진행합니다.

글 · 안상선 ((주)M-Robo 대표) · Ahn Sangsun

## 사다리 4칸

1. **학습표** — 품질 측정 한 번 = 한 문제. 입력은 37분 전 온도·산소와 37~46분 전 온도 평균. 269줄 중 6줄 제외(그림자 5 + 맨 앞 1) → 263줄.
2. **소프트센서** — 랜덤포레스트(나무 120). 시간순 + 60분 간격 시험 MAE 0.262점(평균만 찍기 1.842). 시차 없는 입력은 1.276.
3. **시험 방법** — 무작위 분할 0.285~0.314(뽑기 번호별), 시간순 + 간격 0.255~0.262(간격 0~120분). 시험 53줄 중 52줄이 바로 옆 15분 줄을 공부에 둔 무작위 분할의 함정.
4. **확인 카드 C** — 미래 정보 · 등록 시각 · 정지 구간 · 미래 MAE · 재평가 계획. 판정: 사용 검토 / 보완 후 재검증 / 보류.

**대결:** 그림자 포함 268줄 vs 정상 운전 263줄 — 미래 기간 MAE 1.069 vs 0.262 (그림자 19:00 줄 한 곳에서 37점 오차).
