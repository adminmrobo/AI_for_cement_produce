# AI를 활용한 시멘트 공정 최적화

시멘트 공장의 데이터로 품질을 미리 맞히고, 그 답을 믿어도 되는지 따지고, 단가를 붙여 가장 알맞은 운전을 찾는 강의의 주차별 인터랙티브 해설 페이지입니다. 박사·조수(하루)·초파리 연구원·주판봇이 진행합니다.

**▶ 바로 보기:** https://adminmrobo.github.io/AI_for_cement_produce/

글 · 안상선 ((주)M-Robo 대표) · Ahn Sangsun
