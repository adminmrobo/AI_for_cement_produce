박사

대상은 세 번 바뀌어도 절차는 하나입니다. 데이터를 맞추고, 믿을 만한지 따지고, 값을 붙여 경계선을 찾는다. 세 번째에는 손이 먼저 움직일 겁니다.

중간고사 이전 (1~6주)

공개된 실제 실험 데이터로 회귀 모델을 구축하고, 데이터 분할과 과적합 문제를 직접 경험하며 검증 방법론을 학습합니다.

중간고사 이후 (8~14주)

시간 지연이 존재하는 공정 시계열 데이터를 다루어 소프트센서를 구현하고, 요인 분석 결과를 경제성 평가로 연결해 최적 운전점을 도출합니다. 마지막으로 이미지 인식·이상 감지·강화학습·대규모 언어모델 등 주요 AI 모델 계열의 특성과 산업 적용 타당성을 판단하는 기준을 다룹니다.

학습 목표

  1. 제조 현장의 비용과 품질이 어떻게 상충하는지 이해하고, 이를 데이터 문제로 정식화한다.
  2. 데이터 전처리, 학습·검증 데이터 분할, 성능 평가 지표의 선택 기준을 학습한다.
  3. 과적합과 데이터 누수를 직접 경험하고, 좋아 보이는 결과를 검증하는 능력을 기른다.
  4. 설명가능 AI(SHAP)를 통해 모델의 판단 근거를 해석하고 공정 언어로 설명한다.
  5. 분석 결과를 비용으로 환산하여 예측을 의사결정으로 전환한다.
  6. 주요 AI 모델 계열의 특성과 적용 조건, 한계를 판단한다.
